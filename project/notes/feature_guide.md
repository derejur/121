# Руководство по признакам (версия 0.1)

Каждый признак: `True` / `False` / `None`. **`None` = в описании не сказано или нужна юридическая трактовка.**
Правило с `None` не должно срабатывать молча: движок помечает группу «зависит от трактовки».

| Признак | Определение | Как ставить | Откуда потребность (правило) |
|---|---|---|---|
| `is_food_purpose` | Товар предназначен для употребления в пищу человеком | `True`, если в описании есть пищевое назначение. Препарат, где еда лишь носитель для лекарства = `False` | N30_1a, E2106_food, S04_scope |
| `is_edible` | Пригоден для употребления в пищу | `False` для технического/кормового сырья, непригодного в пищу | N02_1a |
| `is_medical_purpose` | Заявлено лечебное, профилактическое или диагностическое назначение | БАД без заявлений о лечении/профилактике болезней = `False` | S30_scope, N21_1e |
| `is_intravenous_nutrition` | Питательный препарат для внутривенного введения | редкий признак, по умолчанию `False` | N30_1a |
| `is_animal_origin` | Основной характер продукта животный (не смесь с преобладанием растительных компонентов) | готовые блюда с малой долей мяса = `False` | S04_scope |
| `is_cell_cultivated` | Получен культивированием клеток in vitro | из описания метода производства | информативный, в правилах пока не участвует |
| `is_meat` | Компонент признаётся «мясом» в смысле гр. 02 / 16 | **юридический вопрос**: для клеточной массы ставить `None` до решения эксперта или перебирать в развилке | S02_title, N16_1, N16_2, N21_1d |
| `processing_state` | `fresh`, `chilled`, `frozen`, `salted`, `dried`, `smoked` (состояния гр. 02); `cooked`, `canned`, `other_prepared` (приготовленный); `formed_with_additives` и т.п. = не определено | по описанию; формованный продукт со связующим и добавками пока считаем неопределённым (`None`) | E02_states, N16_1 |
| `state_matches_group02` | Производный: `True` для 6 состояний гр. 02, `False` для приготовленных, иначе `None` | вычисляется движком; в развилке можно задать вручную | E02_states, N16_1, named_elsewhere |
| `meat_share_pct` | Доля мяса/мясного компонента в готовом изделии по массе, % | из состава; учитывается только при `is_meat=True` | N16_2, N21_1d |
| `has_proteolytic_enzymes` | Есть протеолитические ферменты (например папаин) | трансглутаминаза = связующее, **не** протеолитический | E02_enzymes (справочно) |
| `is_enzyme_preparation` | Сам товар это ферментный препарат (3507) | продукт, где ферменты основа, а не добавка | N21_1g |
| `is_dairy_egg_honey` | Молоко, молочные продукты, яйца, мёд | по описанию | S04_scope, named_elsewhere |
| `named_elsewhere_other` | Продукт поименован в другой позиции, не учтённой правилами | вводит эксперт; `None` если не выяснено | E2106_cond, S04_scope |

## Спорные случаи

- **«Мясо» для клеточной массы.** Тексты Примечаний и Пояснений не определяют термин «мясо». Решение принимать не автоматически, а через развилку.
- **Формованный продукт со связующим.** Гр. 02 допускает только 4 состояния и не приготовленное мясо; про формование со связующим в приложенных текстах нет. Признак `None`.
- **Добавки (мальтодекстрин).** В гр. 02 описаны допустимые добавки только сахар и протеолитические ферменты; критерий для прочих добавок в приложенных текстах не найден.
- **0410 против 2106.** Обе остаточные; критерий выбора не найден в приложенных текстах (ОПИ не приложены).
